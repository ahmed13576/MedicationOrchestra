# Medication Orchestra Agent — Project Context

You are building **Medication Orchestra**, a Flutter + Google Cloud Run app for the Google Hackathon (Concierge Agents track).

## What This Project Does
A household medication safety agent:
1. User photographs a prescription (printed or handwritten Indian prescription)
2. Gemini Vision extracts medications, doses, Indian notation (OD/BD/TDS/QID/SOS/HS/AC/PC)
3. ADK checks ALL household medications against DrugBank DDI dataset via Vertex AI Vector Search
4. App shows plain-language interaction alerts with severity (Contraindicated/Major/Moderate/Minor)
5. Suggests safe time gaps between interacting medications
6. Sends FCM push reminders at scheduled dose times
7. SOS button sends emergency interaction report to family members

## Tech Stack (DO NOT deviate from this)
- **Frontend**: Flutter (Dart) — single codebase for Android + iOS + Web
- **Backend**: Python FastAPI on Cloud Run
- **Agent Framework**: Google ADK (google-adk package)
- **AI**: Gemini 2.0 Flash (via google-genai SDK)
- **Database**: Firestore (NoSQL)
- **Auth**: Firebase Auth (email/password + anonymous)
- **Notifications**: Firebase Cloud Messaging (FCM)
- **RAG**: Vertex AI Vector Search
- **CI/CD**: Cloud Build + Artifact Registry
- **Testing distribution**: Firebase App Distribution

## Critical Rules
1. **NEVER store prescription images permanently** — process with Gemini Vision, then delete
2. **ALL health data in Firestore** with user-scoped security rules — never a shared DB
3. **Medical disclaimer** on every screen that shows drug information
4. **Test on physical Android device** — FCM does not work reliably on emulators
5. **Use Gemini 2.0 Flash** (not Pro) for all calls — faster, cheaper, sufficient for this task
6. **Follow the 4-day sprint plan** in the spec — do not over-engineer
